# Actividad #1 - Fundamentos de Python

## Ejercicios
1. **Ejercicio 1:** Estructura de estudiante con notas
   - Promedio general
   - Mejor y peor nota
   - Aprueba (promedio ≥ 3.0)

2. **Ejercicio 2:** Cálculo de impuestos y descuentos
   - Impuesto del 19%
   - Descuento del 10% si valor ≥ 200000

3. **Ejercicio 3:** Serie Fibonacci
   - Genera serie desde 1
   - Número de iteraciones definido por usuario

4. **Ejercicio 4:** Menú de operaciones
   - Número primo
   - Factorial
   - Contador de vocales

5. **Ejercicio 5:** Validaciones
   - Nombre (mínimo 3 caracteres)
   - Edad (0-120)
   - Correo (@, .com o .edu.co)

## Cómo ejecutar
```bash
python ejercicio1_estudiante.py
python ejercicio2_calculo_valor.py
python ejercicio3_serie_fibonacci.py
python ejercicio4_operaciones.py
python ejercicio5_validaciones.py
